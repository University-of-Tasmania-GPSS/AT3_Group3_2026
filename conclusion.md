# Conclusion

**There is no single right karst vulnerability map. Every choice moves it, some far more than others.**

## What made it hard

- **No ground truth.** Nothing measures contamination, so the only check is where springs are, and springs mark where water leaves.
- **Scores are judgement.** Land-use scores, slope direction and class edges are choices. Published methods disagree even on the sign of slope.
- **Data has gaps.** DEA cannot see plantations, LIST is a single year, and the 2 m DEM exists only at Mole Creek.
- **Scale changes the answer.** The 100 m run is thin for small polygons, and 132 had no cell at all.
- **A product squeezes scores.** Four terms below 1 multiply to small numbers, so the first risk classes hid all variation.

## What it means

- A map is a set of choices. Show them, and show how far each one moves the result.
- Pick the combination that fits the question: local detail or a state-wide screen.
- Build in a way that others can rerun and change.
